## A. 硬风险源核查清单（杀手锏，优先级高于任何口碑帖）

### A0. 实体对齐红线（最先做，最易错）
- 用户说的「公司名」常是**品牌 / 业务线名**，不是法律主体。用品牌名直接搜硬数据会查错主体，结论全盘皆错。
- 先对齐再查：确认「实际雇主法律主体全称 + 统一社会信用代码」。
- 真实案例：用户说「贝壳惠居（宁波）」→ 实际雇主是 **宁波格调房屋租赁有限公司**（91330212MA2KPW555Q，贝壳投资控股全资子公司，本地小型子公司），**不是**「贝壳找房（北京）科技有限公司」分公司。错把品牌当北京母公司会误判「上市公司母体、风险低」。
- 集团子公司要分别查：母公司合规 ≠ 本地子公司合规。
- 置信度自检：若推演出主体名 / 代码却说不出真实来源 → 视为未验证，禁止写进报告。

### A0.5 关系穿透（关联实体诉讼核查）——最易漏的致命盲区
- 只搜母品牌主体会严重低估风险。很多劳动纠纷 / 欠薪官司藏在关联公司 / 劳务派遣子公司 / 分公司里，母体"干净"只是结构性烟幕。
- **零门槛默认路径（纯公开检索即可）**：
  1. 挖关联实体：`公司全称 + 对外投资 / 控股子公司 / 分公司 / 分支机构`
  2. 补股权结构：`公司名 + 子公司工商登记公告 / 新三板 对外投资`
  3. 筛用工相关壳：名称含 劳务 / 人力 / 人力资源 / 保安 / 外包 / 各城市分公司
  4. 逐个查诉讼：`壳公司名 + 劳动争议 / 劳动合同纠纷 / 裁判文书网`
  5. 交叉验证：壳与母诉讼合并，判断风险是否藏在壳里
- 增强层（用户已连接则调用）：企百科 MCP（免费额度，股权穿透 / 疑似实控人 / 多节点）、水滴 MCP（cisp-mcp，中小企业免费关系图谱）。
- 网页免费查：88查（88cha.com，网页全免费含穿透 + AI 背调，但开放 API 是付费单公司维度）、爱企查（aiqicha.baidu.com，永久免费无限制，是手动免费查首选，但有企业认证门槛、穿透评级"中"）。
- 付费兜底：企查查 / 天眼查连接器（穿透图谱最深，需自连 + 付费账号）。
- **能力边界**：公开检索能确认结构 + 找到几个壳的诉讼片段，但拉不全 100+ 成员企业全貌；免费 MCP 也可能未穷举，报告中须标注「关联实体诉讼可能未穷举，置信度中」。

### A1. 中国裁判文书网 · 劳动争议
- 地址：https://wenshu.court.gov.cn
- 查：`公司全称 + 劳动争议`（或 劳动合同纠纷 / 追索劳动报酬 / 经济补偿金）
- 解读：数量近年变多 = 管理恶化 / 裁员纠纷上升；`追索劳动报酬 / 加班费` = 欠薪信号；`违法解除劳动合同` = 随意裁人；被告多为本公司 = 系统性而非个例。
- 置信度：高（真实司法记录）。需用法律主体全称搜，子公司单独搜。

**⚠️ 关键区分（案由决定信号灯）**
| 案由 | 对求职者含义 | 信号 |
|---|---|---|
| 劳动争议 / 劳动合同纠纷 / 追索劳动报酬 / 经济补偿金 | 公司 vs **员工**（欠薪、违法解除、加班费）→ 直接雇佣风险 | 🔴 强红 |
| 房屋租赁合同纠纷 / 租赁合同纠纷 | 公司 vs **租客/房东**（包租业务摩擦）→ 揭示业务模式与岗位性质 | 🟡 业务信号 |
| 财产损害赔偿 / 侵权责任纠纷 | 经营偶发事故 | 🟡 弱信号 |

误区：一家公司 40+ 风险、60+ 司法案件看似吓人，若绝大多数是租赁合同纠纷，说明的是它做"省心租 / 包租"业务、与租客摩擦多——告诉你岗位是收房/出房/催收/租后的高强度运营，**不是"公司会坑员工"**。

### A2. 中国执行信息公开网 · 失信 / 限高
- 地址：https://zxgk.court.gov.cn
- 查：公司名 → 是否「失信被执行人」（老赖）、是否「限制高消费」
- 解读：失信被执行 = 有履行能力而拒不履行（常见于欠薪欠款）→ **强红灯**；多条限高 = 资金链紧张。置信度：高。

### A3. 国家企业信用信息公示系统 · 年报 / 处罚
- 地址：https://www.gsxt.gov.cn
- 查：企业年报 →「参保各险种人数」（报告期末 = 12.31 职工数）；行政处罚、经营异常、股权冻结、严重违法失信名单。
- 解读：参保人数**同比连续下降** = 收缩 / 裁员硬证据；行政处罚（劳动/社保/消防类）= 合规风险；经营异常（地址失联、未年报）= 管理混乱前兆。
- 置信度：高（官方）。注意：是**年度净变化**非月度；受社保代缴 / 外包、试用不缴、集团内调动干扰；小微企业年报真实性企业自负。

### A4. 黑猫投诉
- 地址：https://tousu.sina.com.cn
- 查：`公司名 + 欠薪 / 离职 / 工资`；也看消费类投诉反映经营状况。
- 解读：集中「拖欠工资」「被迫离职不补偿」= 劳动风险信号；单条孤例权重低，群发才显著。

### A5. 信用中国（可选补充）
- 地址：https://www.creditchina.gov.cn
- 查：行政处罚、失信惩戒信息，与公示系统互补。

### A6. 核查结论分级（写进报告）
| 信号 | 红灯含义 | 权重 |
|---|---|---|
| 失信被执行 / 限高 | 欠款欠薪老赖，慎入 | 一票否决级 |
| 劳动争议数量近年飙升 | 管理恶化 / 裁纠纷 | 高 |
| 年报参保人数连续下降 | 收缩裁员 | 高 |
| 行政处罚（劳动/社保） | 合规风险 | 中高 |
| 黑猫集中欠薪投诉 | 劳动风险 | 中 |

### B1.5 口碑替代源（小红书天然盲区补强）
> **关键事实**：小红书内容**不被搜索引擎收录**（百度不主动抓取），纯 WebSearch 用 `site:xiaohongshu.com 公司名` 基本只返回首页、抓不到具体避雷帖。本 skill **无法主动检索小红书**——不是疏漏，是技术限制。用三条路径补强"小红书式"真实员工口碑（领导风格 / 加班真相 / 离职原因 / 职场霸凌）：
> - **知乎（口碑主力）**：`公司名 工作体验 OR 真实经历 OR 离职 原因`、`公司名 领导 风格 OR 加班 真相`、`公司名 避雷 OR 劝退`，以及 `site:zhihu.com 公司名 小红书`（常能搜到被转到知乎的原小红书帖）。
> - **百度贴吧 + 微博**：`公司名吧` / `公司名 贴吧 加班 真实员工`；微博 `公司名 避雷 OR 欠薪`，常搜到被转发的原小红书 / 脉脉片段。
> - **用户贴链接**：强烈引导用户把小红书刷到的避雷帖（截图 / 原文 / 一句话）发进来，skill 拿去硬源交叉验证（见 B4 第 4 步）。

### B1.6 创始人 / 实控人画像与战略变化（零门槛 WebSearch，高价值盲区）
> 创始人公开言论、战略新闻、工商变更**均被搜索引擎正常收录**（不像小红书），纯 WebSearch 直跑，无需登录 / T1。硬风险源查不到「老板画饼」「业务要砍」，只能靠这一层补。中层 / 高管必查，基层可选。
> - **创始人言论**：`创始人名 公司名 微博 OR 公众号 OR 采访 OR 内部信`、`创始人名 公司名 996 OR 员工 言论` → 画饼 / 狼性 / 怼员工 = 文化压榨软信号（[L3 口碑]）。
> - **工商变动硬信号**：`公司名 法定代表人 变更`、`公司名 股东 退出 OR 股权质押`、`创始人名 公司名 套现 OR 离场` → 套现离场 / 高比例质押 = 治理强红（[L1 硬数据]）。
> - **战略变化**：`公司名 战略 转型 OR 收缩 OR 关停`、`公司名 融资 OR 上市 OR 并购`；源：36氪 / 晚点 / 亿欧 / 雪球 → 关停业务线 = 该岗明年高危（[L3 口碑]）。
> - 落位：并入「治理与决策权」维度；高管强制核查追加「创始人言行与战略一致性 / 有无套现离场信号」；面试必问「今年收缩还是扩张某业务线，我岗是否在调整范围」。

### B1.7 薪资市场基准（横向：offer vs 市场区间）
> 招聘平台（Boss / 猎聘 / 智联 / 看准 / 职友集）按「岗位 + 城市」暴露薪资区间；人社部劳科院另发 per-role per-region 市场平均招聘薪酬（免费权威）。常见岗 + 一二线质量中高。**限制**：招聘薪 vs 到手差 10–30%、同 title 职级 / 职责不可直接比、冷门岗稀薄 → 稀薄标「无法评估」，不编百分位。
> - 检索：`岗位名 城市 薪资 2026` / `岗位名 城市 看准 薪资爆料`。
> - 用法：有 offer → 拉区间标「高于 / 持平 / 低于市场水位」；无 offer → 只给区间作谈薪参考；跨城跨级须同口径（岗位 + 城市 + 经验档）；冷门岗标无法评估。
> - 坑：招聘薪常含总包，到手低 10–30% 提醒看 base；同 title 不同 scope 不可直接比。

### B2. 高级语法
- 避雷定向：`"公司名 避雷"`、`"公司名 加班 裁员"`、`"公司名 年终奖 不发"`
- 风险定向：`公司名 劳动仲裁 OR 欠薪 OR 行政处罚`、`公司名 失信被执行`
- 面经定向：`公司名 面试 体验 OR 流程`、`公司名 面经 薪资`
- 实体收敛：公司名常见时加城市 / 行业，如 `公司名 宁波 制造业`

### B3. 去噪与可信度
- 孤例 vs 普遍：1 条吐槽权重低；同主题在 3+ 独立来源出现 = 显著信号。
- 水军 / 竞品抹黑识别：清一色无细节极端负面、账号新、时间集中 = 警惕；有具体时间 / 人物 / 事件细节更可信。
- 时间衰减：2 年前吐槽若近 1 年无同类可能已改善；近期密集 = 恶化。
- 交叉验证优先：口碑说「年终奖不发」→ 去裁判文书网 / 黑猫看有无对应欠薪证据；有硬证据撑的口碑置信度直接升级。

### B4. 检索节奏
1. 第一轮：分平台广撒网（看准 / 牛客 / 黑猫 / **知乎（口碑主力）** / 贴吧 / 微博 / 新闻）
2. 第二轮：针对红旗定向深挖（仲裁 / 裁员）
3. 第三轮：硬风险源核查（本节 A）
4. 若用户带小红书避雷帖 → 拿去硬源验证（交叉验证关键一步）

## C. 招聘黑话解码表（听 HR / 面试官怎么说）

| 公司话术 | 真实含义（高概率） |
|---|---|
| 「抗压能力强 / 能接受挑战」 | 加班多、活杂、容易背锅 |
| 「扁平化管理」 | 无清晰晋升层级，或老板一言堂 |
| 「弹性工作」 | 无明确上下班时间，通常 = 随时在线 |
| 「有创业精神」 | 人少事多、流程缺失、权责模糊 |
| 「团队年轻有活力」 | 流动率高、缺乏资深把关 |
| 「提供有竞争力的薪酬」 | 往往没具体数字，避谈 base |
| 「我们像大家庭」 | 边界感弱、易道德绑架 |
| 「快速成长 / 高速发展」 | 可能伴随频繁组织调整、方向摇摆 |
| 「愿意与公司共同成长」 | 短期薪资可能低于市场 |

解码原则：话术本身不扣分，但「只谈愿景、回避具体数字 / 制度」= 风险信号。

## D. 面试反问清单（三档，按阶段触发）

### 🟢 温和探问（投前 / 一面）
- 「这个岗位的上一任为什么离开？团队平均在职多久？」
- 「团队目前几个人，近一年有人员变动吗？」
- 「这个岗位的日常协作方是谁，汇报线是怎样的？」

### 🟡 直球验证（终面 / 谈薪）
- 「绩效考核怎么算？绩效工资占比多少？」
- 「年终奖的基数和发放标准是什么？去年实际发放了几个月？」
- 「五险一金的缴纳基数按什么？按全额还是最低基数？」
- 「试用期多久，转正条件是什么？」

### 🔴 压力测试（拿 offer 前）
- 「如果项目延期，加班怎么算？调休能兑现吗？」
- 「如果遇到经营波动，这个岗位会被优先保护还是调整？」
- 「offer 里的薪资结构，哪部分有保底、哪部分浮动？」

阶段映射：投前 → 🟢；面试中 → 🟢+🟡；拿 offer → 🟡+🔴 必问。

### offer 谈判要点（若决定接）
- base 底线写进 offer，不接受口头承诺
- 绩效占比上限问清（超过 30% 浮动需警惕）
- 期权 / 股权行权条件、退出机制必须书面
- 试用期时长、转正条件、离职补偿条款逐条确认

## E. 诚实标注规则
- 每条结论带来源层级：`[L1 硬数据]` / `[L3 口碑]` / `[L4 用户情报]`。
- 数据稀薄处明确写「无法评估」，不臆造。
- 小红书类用户情报若未能在硬源找到支撑，标注「待验证，暂作参考」。
- **技术边界必须明确告知用户**：
  - WebSearch 对裁判文书网/企查查等反爬平台只能命中摘要，无法逐条导出；
  - 关联实体诉讼穷举需依赖付费商查工具（企查查/启信宝）或手动网页核查；
  - 报告应提供可操作的手动验证路径（如「打开88查→输入公司名→点司法风险」）。
