# 硬风险源核查清单

> 这是本 skill 的**杀手锏**——普通求职者绝不会自己查、但最能一票否决的硬证据。
> 优先级高于任何口碑帖。每条核查结果都要标注「来源层级 L1（硬数据）」与置信度。

---

## 0. 实体对齐红线（最先做，最易错）

> **致命坑**：用户说的「公司名」往往是**品牌/业务线名**，不是法律主体。用品牌名直接搜硬数据，
> 会查到错误主体，结论全盘皆错。

- **先对齐再查**：拿到公司名后，第一步用 WebSearch / 企查查 / 天眼查确认「实际雇主的法律主体全称 + 统一社会信用代码」。
- **品牌≠主体 的真实案例**：用户说「贝壳惠居（宁波）」→ 实际雇主是 **宁波格调房屋租赁有限公司**
  （`91330212MA2KPW555Q`，贝壳投资控股集团全资子公司，本地小型子公司），**不是**「贝壳找房（北京）科技有限公司」分公司。
  错把品牌当北京母公司，会误判「上市公司母体、风险低」。
- **集团旗下子公司要分别查**：母公司合规 ≠ 本地子公司合规。资管经理/一线岗的实际雇主常是城市的运营子公司，
  必须**单独搜该子公司**的硬风险。
- **置信度自检**：若你"推演"出了一个主体名或信用代码，却说不出它来自哪条真实搜索结果 → 视为未验证，禁止写进报告。
  （反例：凭印象写的信用代码 `91440300MA5EMY1169` 前缀是深圳码，与"北京"矛盾，属编造。）

## 0.5 关系穿透（关联实体诉讼核查）——最易漏的致命盲区

> **血的教训（来自真实案例实测，已脱敏）**：只搜母品牌主体，会严重低估风险。许多公司的
> 劳动纠纷、欠薪官司藏在**关联公司 / 劳务派遣子公司 / 分公司**里，母体看起来"干净"
> 只是结构性烟幕。求职者的真实雇主也常是这些壳之一。

### 什么叫"关系穿透"
拿到主实体后，**必须**拉出它的关系网，再逐一对每个"用工相关"的关联实体查诉讼：
- **对外投资 / 子公司 / 孙公司**（尤其名称含 劳务 / 人力 / 人力资源 / 保安 / 外包 / 服务 的）
- **分公司**（各地分公司常是实际用工方，且各自有独立劳动争议案）
- **曾用名 / 品牌别名**（同信用代码的不同牌子，不是不同主体）

### 真实证据（真实案例，已核实并脱敏）
- 主公司自述无大劳动风险；但关系网里：
  - `示例保安服务有限公司`（100% 母控，**含劳务派遣许可**）——正是"下设劳务公司"的壳
  - `示例人力资源有限公司`（100% 子公司，做**人才派遣**）
  - 公开工商平台直接给数：**成员企业 109，成员风险 99+**；单一家关联酒店主体 关联风险 **138 条**
- **新三板反馈意见回复（铁证，已脱敏）**：公司自认用劳务派遣做"保安/协警"岗位，并声明与派遣公司
  「不存在关联关系」；如今自己控股劳务派遣公司 = **把派遣壳内化**，即"用关联劳务公司隔离用工风险"。

### 求职者必问（把隐性风险显性化）
面试/谈薪时务必问清三个主体是否一致，不一致即红旗：
> "我的**劳动合同**跟哪家公司签？**社保**由哪家缴？**实际工作 / 发薪**主体又是哪家？"

若合同主体 ≠ 社保主体 ≠ 实际用工主体（即用户说的"社保与合同非同主体"），说明公司在做
**用工风险隔离**——一旦出事，维权对象分散、取证困难。

### 零门槛默认路径：WebSearch 系统化穿透（无需任何连接，人人可用，首选）

> **实测结论（真实案例探针，已脱敏）**：纯 WebSearch **零门槛即可完成关系穿透**，不需要连任何 MCP、不需要登录、不需要 API key。
> 搜索引擎索引了天眼查 / 企查查 / 水滴 / 东方财富等平台的**公开页快照**，直接返回完整「对外投资 / 子公司 / 分公司」列表与部分关联诉讼。
> 这是最便捷无门槛的路径，应作为每家公司关系穿透的**默认第一步**。

**系统化搜索词（五步工作流里对每家公司自动执行）：**
1. 挖关联实体：`公司全称 + 对外投资 / 控股子公司 / 分公司 / 分支机构` → 命中天眼查/企查查/水滴公开页，拿到 60+ 子公司清单（含劳务/人力/保安壳）
2. 补股权结构：`公司名 + 关于子公司完成工商登记公告 / 新三板 对外投资` → 命中东方财富等公告，含信用代码与持股比例
3. 筛「用工相关壳」：从清单挑名称含 劳务 / 人力 / 人力资源 / 保安 / 外包 / 各城市分公司 的实体
4. 逐个查诉讼：`壳公司名 + 劳动争议 / 劳动合同纠纷 / 裁判文书网` → 命中标的相关公开页
5. 交叉验证：把壳公司诉讼与母主体诉讼合并看，判断「用工风险是否藏在壳里」

### 增强层（可选，连 MCP 后自动调用）

- **企百科 MCP**（中数智汇，央行备案征信机构）：免费额度，MCP「关联关系」模块支持股权穿透 / 疑似实控人 / 多节点最短路径，可拉更完整的关联图谱。已上架 TraeWork / 千问 / QClaw 等，用户自连即用。
- **水滴 MCP**（`cisp-mcp`，凭安征信，央行上海备案）：中小企业免费，自然语言查股权 / 关系图谱。本机若已连，直接可用。
- **适用场景**：WebSearch 没挖全、或用户想看可视化穿透图时，连其一增强。重度批量会触额度上限，但求职者「查几家公司」量级完全够。

### 网页免费查（零成本、手动）

- **88查**（阿里，88cha.com）：个人网页 / 小程序**全免费**（含股权穿透、关联图谱、AI 背调），手机号注册即用。但开放 API 是**付费单公司维度**（不暴露深度穿透接口），因此**关系穿透主力在网页版手动查**，查完把 AI 背调报告粘进来（补 skill 盲区，合理）。
- **爱企查**（百度）：全部功能**永久免费、无次数限制**，是**手动免费查的首选入口**（比 88查额度版、企百科积分版更宽松）。它**确有开放 API 与企业 MCP（handaas enterprise-mcp-server）**，但开放 API 需**企业资质认证（营业执照+法人身份证）**、个人用户门槛高；且其**关联图谱完善度低、多节点关联不足（穿透评级"中"）**——故不做自动穿透主力，定位为「手动免费核验源 + WebSearch 命中源」。

### 付费兜底（最深但收费）

- 企查查 / 天眼查连接器（`qcc-company` / `tyc-mcp`）：自身风险 / 周边风险 / 股权穿透图谱功能最全，但需用户自连 + 付费账号。

### 能力边界（务必诚实写进报告）

- WebSearch **能确认结构**（确实存在劳务 / 人力关联壳、能翻到自认派遣的官方文件、能找到几个壳的诉讼片段），但**拉不全全貌**。
- 免费 MCP（企百科 / 水滴）可程序化拉出关联图谱与核心壳诉讼，但仍可能未穷举 100+ 成员企业全部诉讼；需在报告中标注「关联实体诉讼可能未穷举，置信度中」。
- 88查 / 爱企查网页版可补充人工核查，但依赖用户手动。
- **一句话**：关系穿透**默认零门槛走 WebSearch 系统化搜索**（无需任何连接，人人可用）；企百科 / 水滴 MCP 为可选增强；深度全量穿透图仍需付费连接器兜底。

## 1. 中国裁判文书网 · 劳动争议
- **地址**：https://wenshu.court.gov.cn
- **查什么**：搜索 `公司全称 + 劳动争议`（或 劳动合同纠纷 / 追索劳动报酬 / 经济补偿金）
- **怎么解读**：
  - 数量趋势：近 1–2 年官司变多 = 管理恶化 / 裁员纠纷上升
  - 案由类型：`追索劳动报酬`「加班费」= 欠薪/无偿加班信号；`违法解除劳动合同` = 随意裁人
  - 被告是否多为本公司 = 系统性而非个例
- **置信度**：高。这是真实司法记录，比口碑可信一个量级。
- **注意**：需用「法律主体全称」搜；用户实际雇主可能是子公司，要分别搜集团母公司+子公司。

### ⚠️ 关键区分：劳动争议 vs 其他案由（对求职者意义完全不同）

搜出来的官司**不一定是雇佣风险**。务必看「案由」分类，否则会误判：

| 案由 | 对求职者的含义 | 信号灯 |
|---|---|---|
| **劳动争议 / 劳动合同纠纷 / 追索劳动报酬 / 经济补偿金** | 公司 vs **员工**的纠纷（欠薪、违法解除、加班费）→ **直接雇佣风险** | 🔴 强红 |
| **房屋租赁合同纠纷 / 租赁合同纠纷** | 公司 vs **租客/房东**的纠纷（包租模式业务摩擦）→ 揭示**业务模式与岗位性质**，非用工恶劣 | 🟡 业务信号 |
| **财产损害赔偿 / 侵权责任纠纷** | 多为经营中的偶发事故 | 🟡 弱信号 |

- **误区纠正**：一家公司有 40+ 自身风险、60+ 司法案件，看似吓人，但若绝大多数是「租赁合同纠纷」，
  说明的是它做"省心租/包租"业务、与租客摩擦多——**这告诉你岗位是收房/出房/催收/租后的高强度运营，
  而不是"公司会坑员工"**。对求职者，前者是岗位画像，后者才是红灯。
- **实操**：在爱企查/企查查的「开庭公告」「司法案件」列表里，抽样看案由；若以租赁纠纷为主且搜不到劳动争议，
  则「用工合规」维度不亮红灯，但要在报告里把"业务摩擦型高诉讼"作为岗位性质信号写明。

## 2. 中国执行信息公开网 · 失信/限高
- **地址**：https://zxgk.court.gov.cn
- **查什么**：公司名 → 是否「失信被执行人」（老赖）、是否「限制高消费」
- **怎么解读**：
  - 被列为失信被执行 = 有履行能力而拒不履行（常见于欠薪、欠款）→ **强红灯**
  - 多条限高记录 = 资金链紧张
- **置信度**：高（官方执行信息）。
- **意义**：欠薪重灾区的硬标志，比任何吐槽都管用。

## 3. 国家企业信用信息公示系统 · 年报/处罚
- **地址**：https://www.gsxt.gov.cn
- **查什么**：
  - 企业年报 →「参保各险种人数」（报告期末=12.31 职工数）
  - 行政处罚、经营异常、股权冻结、列入严重违法失信名单
- **怎么解读**：
  - 参保人数**同比连续下降** = 收缩/裁员硬证据（例：81→62→44→37→32）
  - 行政处罚（劳动/社保/消防类）= 合规风险
  - 经营异常（地址失联、未年报）= 管理混乱前兆
- **置信度**：高（官方）。但注意：
  - 这是**年度净变化**，非月度，不能推算月流失率
  - 受社保代缴/外包、试用不缴、集团内调动干扰，部分数字失真
  - 小微企业年报真实性企业自负，偶有乱填

## 4. 硬数据自动层（免费 MCP / 连接器可选，非必需）

下列任一数据源若用户已连接 / 已配 key，硬风险核查可自动拉取更全的工商 / 诉讼 / 穿透数据；**都不连也完全能跑**（走 WebSearch + 政府官网 1–3）。

- **企百科 MCP**（推荐首选）：免费额度，MCP 含「关联关系」模块，支持股权穿透 / 疑似实控人 / 多节点，是关系穿透免费自动解。
- **水滴 MCP**（`cisp-mcp`，本机可能已连）：中小企业免费，自然语言查股权 / 关系图谱。
- **蚂蚁 MCP**（魔搭云部署）：基础工商 + 风险，免费门槛低，免自建。
- **88查**：网页版免费（含穿透 / AI 背调）宜手动查后粘报告；开放 API 为付费单公司维度，用户自备 appcode 可增强。
- **企查查 / 天眼查**（`qcc-company` / `tyc-mcp`）：自身风险 / 周边风险 / 股权穿透图谱最深，但需用户自连 + 付费账号。
- **爱企查**：网页 / App 全免费（无次数限制），是**手动免费查首选**；确有开放 API / 企业 MCP，但 API 需企业资质认证、个人门槛高，且穿透评级"中"（弱于企百科/水滴），故仅作手动基础核验 + WebSearch 命中源。

> 提醒：软信号（脉脉 / 小红书口碑）任何硬数据源都拉不到，别指望。

## 5. 黑猫投诉
- **地址**：https://tousu.sina.com.cn
- **查什么**：`公司名 + 欠薪 / 离职 / 工资`；也看消费类投诉反映的经营状况
- **怎么解读**：集中出现「拖欠工资」「被迫离职不补偿」= 劳动风险信号；单条孤例权重低，群发才显著。

## 6. 信用中国（可选补充）
- **地址**：https://www.creditchina.gov.cn
- **查什么**：行政处罚、失信惩戒信息，与公示系统互补。

## 核查结论分级（写进报告）

| 信号 | 红灯含义 | 权重 |
|---|---|---|
| 失信被执行 / 限高 | 欠款欠薪老赖，慎入 | 一票否决级 |
| 劳动争议数量近年飙升 | 管理恶化 / 裁纠纷 | 高 |
| 年报参保人数连续下降 | 收缩裁员 | 高 |
| 行政处罚（劳动/社保） | 合规风险 | 中高 |
| 黑猫集中欠薪投诉 | 劳动风险 | 中 |

> 任何一项触红灯，报告里必须单独高亮，并在「决策建议」中明确提示风险等级。
