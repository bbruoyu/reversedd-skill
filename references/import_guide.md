# 反向背调智能体 · 导入与部署指南

> 把「求职者反向背调」做成可分发产品，让用户 **零安装、零域名备案** 即可使用。
> 本目录提供：核心提示词（`system_prompt.md`）+ 知识库（`knowledge_base.md`）。
> 下方给出三种落地路径，从「零备案」到「完全自建」逐级递增。

---

## 路径一：腾讯元器（推荐，零域名备案，微信生态）

**适用**：想借微信触达、不想买域名 / 做 ICP 备案。
**成本**：官方渠道 token 免费不限量（需有公众号；个体户可注册认证）。

1. 打开 https://yuanqi.tencent.com ，用**公众号管理员微信**扫码登录（无公众号先去 mp.weixin.qq.com 注册一个，个体户可认证）。
2. 左侧「个人空间」→「创建智能体」→「用提示词创建」。
3. 名称填「反向背调助手」，简介写「求职者查公司避坑核查」。
4. 把 `system_prompt.md` 全文粘进提示词框；在「知识库」上传 `knowledge_base.md`（或把知识库内容拼进提示词末尾）。
5. 高级设定选模型（DeepSeek 等第三方模型需注意：平台会要求你**自行完成算法备案**，见下「合规提醒」）。
6. 预览调试后点「发布」→ 选「微信订阅号 / 服务号」或「官方小程序」，授权即上线。
7. 发布后获得**小程序码 + 可分享 H5 链接**，可嵌入公众号菜单、转发微信对话 / 群聊，用户在微信内直接打开。**全程无需你买域名、无需 ICP 备案**（链接托管在元器已备案域名下）。

---

## 路径二：扣子 Coze（微信小程序发布，需小程序号）

**适用**：想做成独立微信小程序。
**成本**：需企业 / 个体**微信小程序号** + 微信认证 300 元 / 年（个人号不支持 web-view 接入）。

1. 打开 https://www.coze.cn ，注册登录。
2. 创建智能体，把 `system_prompt.md` 粘入，知识库上传 `knowledge_base.md`。
3. 发布 → 选「微信小程序」→ 填你的小程序 AppID 并授权。
4. 审核 1–7 工作日。发布后用户微信搜 / 扫码即用。
5. 注意：Coze 通过 web-view 接入，**域名为 Coze 已备案域名**，你不需自己买；但使用 DeepSeek 等第三方模型需**自行算法备案**（Coze 文档明示）。

---

## 路径三：Dify 云版 / 自建后端（可控、可接搜索）

**适用**：想完全自有、接搜索 API（替代纯公开检索）、私有化部署。
**成本**：Dify 云版有免费额度；自建需服务器 + 域名 + ICP 备案（个体户可备）。

1. Dify 云版（https://cloud.dify.ai）创建 Chatbot，系统提示词贴 `system_prompt.md`，知识库上传 `knowledge_base.md`。
2. 若要"实时联网检索公司数据"，需在工作流里接搜索工具（如 SerpAPI / Bing Web Search / Brave Search API），并配置 DeepSeek 为推理模型。
3. 前端可发布为 Web App（Dify 自带）或嵌入现有站点。
4. 自建后端为可选：可用 FastAPI（agent loop）+ 搜索工具（可插拔）+ DeepSeek API（system prompt = 本框架）自行搭建，非必须。

---

## 合规提醒（务必看）

1. **算法备案**：在国内平台用 DeepSeek / 第三方模型提供对外服务，通常需完成**大模型算法备案**。Coze / 元器在文档中明确要求使用者自行申请。用平台自带的混元 / 豆包等已备案模型可规避，但功能与成本不同。
2. **涉企内容风险**：本产品核心价值是"摆公司硬伤"，天然与企业立场对立。发布时注意：
   - 所有结论标注**来源层级与置信度**，不做主观贬损、不造谣（"据裁判文书网显示…"而非"这家就是黑心企业"）。
   - 加**免责声明**："本结果基于公开信息整理，仅供参考，不构成求职 / 法律建议"。
3. **小红书引流红线**：在小红书直接留微信 / 二维码 / 谐音（VX / 绿泡泡）导流到站外工具，2025–2026 识别率极高（约 92% 直接导流被监控），新号风险系数更高。**合规做法**：发干货内容自然吸粉，引导站内咨询 / 企业微信（官方合规路径），不在笔记正文留站外联系方式。
4. **不内置密钥**：无论哪条路径，不要把任何 API key 写死在提示词 / 前端；如需搜索 API，让用户自备或走平台能力。
