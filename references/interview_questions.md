# 面试反问清单 + 黑话解码

> 把「背调」前移——在面试现场就能验证风险。按用户当前阶段（投前/面试中/拿 offer）动态生成对应清单。
> 同时附「公司话术 → 真实含义」解码表，帮用户听出弦外之音。

---

## 一、面试反问清单（三档，按阶段触发）

### 🟢 温和探问（投前/一面，建立信任同时摸底）
- 「这个岗位的上一任为什么离开？团队平均在职多久？」
- 「团队目前几个人，近一年有人员变动吗？」
- 「这个岗位的日常协作方是谁，汇报线是怎样的？」

### 🟡 直球验证（终面/谈薪，确认硬条件）
- 「绩效考核怎么算？绩效工资占比多少？」
- 「年终奖的基数和发放标准是什么？去年实际发放了几个月？」
- 「五险一金的缴纳基数按什么？是按全额还是最低基数？」
- 「试用期多久，转正条件是什么？」

### 🔴 压力测试（拿 offer 前，确认边界）
- 「如果项目延期，加班怎么算？调休能兑现吗？」
- 「如果遇到经营波动，这个岗位会被优先保护还是调整？」
- 「offer 里的薪资结构，哪部分是有保底的、哪部分是浮动的？」

> 阶段映射：投前 → 用🟢；面试中 → 🟢+🟡；拿 offer → 🟡+🔴 必问。

## 二、黑话解码表（听 HR/面试官怎么说）

| 公司话术 | 真实含义（高概率） |
|---|---|
| 「抗压能力强 / 能接受挑战」 | 加班多、活杂、容易背锅 |
| 「扁平化管理」 | 无清晰晋升层级，或老板一言堂 |
| 「弹性工作」 | 无明确上下班时间，通常=随时在线 |
| 「有创业精神」 | 人少事多、流程缺失、权责模糊 |
| 「团队年轻有活力」 | 流动率高、缺乏资深把关 |
| 「提供有竞争力的薪酬」 | 往往没具体数字，避谈 base |
| 「我们像大家庭」 | 边界感弱、易道德绑架 |
| 「快速成长 / 高速发展」 | 可能伴随频繁组织调整、方向摇摆 |
| 「愿意与公司共同成长」 | 短期薪资可能低于市场 |

> 解码原则：**话术本身不扣分，但「只谈愿景、回避具体数字/制度」= 风险信号**。
> 把面试官的话术对照上面的清单，在报告「管理文化」维度标注。

---

## 三、offer 谈判要点（若决定接）
- base 底线写进 offer，不接受「口头承诺」
- 绩效占比上限要问清（超过 30% 浮动需警惕）
- 期权/股权行权条件、退出机制必须书面
- 试用期时长、转正条件、离职补偿条款逐条确认
