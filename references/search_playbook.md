# WebSearch 多源检索话术与高级语法

> 本 skill 的**主干数据层**。零设置、人人可用。目标是跨平台聚合「公司评价 + 风险信号」。
> 对中小私企/本地小厂覆盖可能稀薄——此时如实标注「无法评估」，不编造。

---

## 一、分平台检索模板（直接套用）

| 平台 | 搜索语法示例 | 价值 |
|---|---|---|
| **看准网** | `site:kanzhun.com 公司名` / `公司名 看准 评价 薪资` | 公司评分、薪资爆料、面试体验（老牌主阵地） |
| **职友集** | `公司名 职友集 评分` | 公司评分、薪资 |
| **牛客网** | `site:nowcoder.com 公司名 面经` | 面经、技术岗薪资、内推吐槽（互联网岗尤其好用） |
| **黑猫投诉** | `site:tousu.sina.com.cn 公司名 欠薪` | 劳动/消费纠纷线索 |
| **知乎（口碑主力）** | `公司名 工作体验 OR 真实经历 OR 离职 原因` / `site:zhihu.com 公司名 小红书` | 长文真实员工故事，小红书最可靠合法替身 |
| **新闻/百度百家** | `公司名 裁员 OR 仲裁 OR 经营恶化` | 裁员、仲裁、经营恶化报道 |
| **BOSS/猎聘/智联 公司页** | `公司名 site:zhipin.com OR site:liepin.com` | 招聘平台自带评价区 |
| **百度贴吧** | `公司名吧` / `公司名 贴吧 加班 真实员工` | 地域 / 行业小厂真实吐槽，收录较好 |
| **微博** | `公司名 避雷 OR 欠薪 OR 离职` | 常搜到被转发的原小红书 / 脉脉片段 |

## 二、口碑替代源（小红书天然盲区补强）

> **关键事实**：小红书内容**不被搜索引擎收录**（百度不主动抓取小红书笔记），纯 WebSearch 用 `site:xiaohongshu.com 公司名` 基本只返回首页、抓不到具体避雷帖。因此本 skill **无法主动检索小红书**——这不是疏漏，是技术限制。
> 但"小红书式"的真实员工口碑（领导风格 / 加班真相 / 离职真实原因 / 职场霸凌）是反向背调的黄金软信号，不能丢。用下面三条路径补强：

### 2.1 知乎 = 最可靠的合法替身（重点加投）
知乎被百度正常收录，且有大量长文真实员工故事，几乎覆盖小红书的核心价值。把它从"顺带搜"升为**口碑主力**：
- `公司名 工作体验 OR 真实经历 OR 离职 原因`
- `公司名 领导 风格 OR 直属上级 OR 996 OR 加班 真相`
- `公司名 避雷 OR 劝退 OR 千万别去`
- `site:zhihu.com 公司名 小红书`（常能搜到被转到知乎的原小红书避雷帖 / 截图）

### 2.2 百度贴吧 + 微博 = 真实吐槽与转发筛查
- **百度贴吧**：`公司名吧` 或 `公司名 贴吧 加班`、`公司名 真实员工 吐槽`——行业 / 地域性小厂尤其有料，且贴吧被收录较好。
- **微博**：`公司名 加班 OR 欠薪 OR 离职` / `公司名 避雷`——常能搜到被转发出来的原小红书帖片段，以及脉脉职言截图。

### 2.3 用户贴链接（小红书唯一可靠入口）
主路径零粘也能跑；但**强烈引导用户把在小红书刷到的避雷帖（截图 / 原文 / 一句话）发进来**。原因同上——用户刷到的那条，skill 自己大概率搜不到。粘进来后，skill 的价值不是"再读一遍帖"，而是**拿这个信号去硬源交叉验证它真不真、有没有硬证据撑**（见 六、检索节奏建议 第 4 步）。

## 三、提升命中率的高级语法

- **避雷定向**：`"公司名 避雷"`、`"公司名 加班 裁员"`、`"公司名 年终奖 不发"`
- **风险定向**：`公司名 劳动仲裁 OR 欠薪 OR 行政处罚`、`公司名 失信被执行`
- **面经定向**：`公司名 面试 体验 OR 流程`、`公司名 面经 薪资`
- **实体收敛**：如果公司名常见，加城市/行业收窄，如 `公司名 宁波 制造业`

## 四、实体对齐（最重要，否则会误导）

搜索常返回多个「同名/关联」主体，必须区分：
- 用户实际雇主可能是**集团子公司 / 关联公司**，而非搜到的「XX 科技有限公司」（参保人数可能差几百倍）。
- 核查时**同时搜母公司 + 子公司 + 品牌名**，并在报告里标注「本次结论针对的法律主体」。
- 例：搜到「小米科技有限责任公司」参保 32 人，但集团员工 6 万——因为用户雇主是具体业务子公司。

## 五、去噪与可信度判断

- **孤例 vs 普遍**：1 条吐槽权重低；同主题（如都骂加班、都说过年不发奖）在 3+ 独立来源出现 = 显著信号。
- **水军/竞品抹黑识别**：清一色无细节极端负面、账号新、时间集中 = 警惕；有具体时间/人物/事件细节的更可信。
- **时间衰减**：2 年前的吐槽，若近 1 年无同类，可能已改善；反之近期密集出现 = 恶化。
- **交叉验证优先**：口碑说「年终奖不发」→ 去裁判文书网/黑猫看有无对应欠薪证据；有硬证据撑的口碑，置信度直接升级。

## 六、检索节奏建议

1. 第一轮：分平台广撒网（看准 / 牛客 / 黑猫 / **知乎（口碑主力）** / 贴吧 / 微博 / 新闻全跑一遍）
2. 第二轮：针对第一轮出现的红旗，定向深挖（如「仲裁」「裁员」）
3. 第三轮：硬风险源核查（见 `risk_sources.md`）
4. 若用户带了小红书避雷帖 → 拿去硬源验证（这是交叉验证的关键一步）

## 七、增强信号（WebSearch 稀薄时补强）

> 以下信号可显著补强中小私企的稀薄数据。全部默认 WebSearch 直跑；商查 MCP 在已连接时增强工商 / 诉讼 / 专利。

### 6.1 专利 / IP 风险（技术驱动型公司必查）
- 搜索：`公司名 核心专利 到期 失效 OR 专利期限届满` / `公司名 专利 快过期 业务线 暴雷风险`
- 含义：核心专利即将到期 = 护城河塌陷，属「成长发展」维度硬信号

### 6.2 招聘历史薪资跑输通胀（薪酬真实度负面）
- 搜索：`公司名 招聘 历史薪资 3年前 对比 跑输通胀` / `公司名 BOSS直聘 同一岗位 半年招聘频次 3次以上` / `公司名 离职率 招聘岗位 长期挂招`
- 含义：同岗薪资经通胀调整仍低于历史 = 增长未惠及员工；同岗半年招 3 次 = 天坑确认

### 6.3 年报 / 财报分析（仅上市公司）
- 触发：实体对齐确认公司为上市公司（有股票代码）才执行
- 方式：运行本地脚本 **`scripts/financial_fetcher.py`**（直连东方财富公开 API，无需密钥、无需后端）获取营收 / 净利 / ROE / 审计意见等摘要：
  `python scripts/financial_fetcher.py --company "浦发银行" --code 600000 -o fin.json`
  再把 `fin.json` 传入渲染器：`python scripts/render_report.py report.md --financials fin.json` 即可在报告中叠加「财务快照（上市公司·东方财富公开数据）」卡。
- 非上市公司无公开年报，本步跳过，「成长发展」维度据工商 / 招聘信号推断并标注

## 八、创始人 / 实控人画像与战略变化（零门槛 WebSearch 可跑，高价值盲区补强）

> **关键事实**：创始人公开言论、战略新闻、工商变更**均被搜索引擎正常收录**（不像小红书），纯 WebSearch 直跑即可，无需登录、无需 T1 浏览器模块。这是低成本高价值补强——硬风险源（裁判文书网 / 公示系统）查不到「老板画饼」「业务要砍」，只能靠这一层。
> 适用层级：中层 / 高管**必查**（预测「这老板值不值得跟」「我的岗是不是明年裁撤对象」）；基层可选（了解大面老板风格即可）。

### 8.1 创始人 / 实控人公开言论（价值观 + 画饼 / PUA 信号）
- `创始人名 公司名 微博 OR 公众号 OR 采访 OR 内部信`
- `创始人名 公司名 996 OR 加班 OR 员工 言论`
- `创始人名 公司名 裁员 OR 降本 OR 狼性`
- 解读：频繁「画饼 / 谈使命不谈钱 / 强调狼性奉献」= 文化偏压榨软信号；公开怼员工 / 否认 996 = 价值观冲突预警。属 **[L3 口碑]**，需多源一致才升级置信度，别把一条极端言论当普遍。

### 8.2 实控人 / 股权变动（硬数据红灯）
- `公司名 法定代表人 变更`
- `公司名 注册资本 减资 OR 增资`
- `公司名 股东 退出 OR 减持 OR 股权质押`
- `创始人名 公司名 套现 OR 离场 OR 卸任`
- 解读：创始人套现离场 / 被查 / 高比例股权质押 = **重大红旗**（治理与决策权维度强红）；法定代表人频繁变更 = 治理不稳。属 **[L1 硬数据]**（天眼查 / 企查查变更记录）。

### 8.3 战略变化（预测岗位存续）
- `公司名 战略 转型 OR 收缩 OR 关停 OR 退出 市场`
- `公司名 新业务线 OR 第二曲线 OR 裁员 业务线`
- `公司名 融资 OR 上市 OR 并购 OR 被收购`
- 来源：36氪 / 晚点 LatePost / 亿欧 / 财经 / 雪球 + 创始人自媒体。
- 解读：关停某业务线 / 退出某市场 = 该线岗位明年高危；持续融资 = 扩张岗机会多但加班重；战略摇摆频繁 = 方向不稳、组织动荡。属 **[L3 口碑]**（媒体叙事，需多源一致）。

### 8.4 落位到报告
- 信号并入「治理与决策权」维度（高管必评；中层建议评创始人 / 战略信号；基层非本层级关切）。
- 高管视角强制核查**追加一条**：创始人言行与战略是否自洽、有无套现 / 离场 / 高比例股权质押信号。
- 面试必问追加：「公司今年在收缩还是扩张某业务线？我这个岗是否属于被调整范围？」

## 九、薪资市场基准（横向：offer vs 市场区间，薪酬真实度维度增强）

> **数据质量说明**：招聘平台（Boss直聘 / 猎聘 / 智联 / 看准 / 职友集）均按「岗位 + 城市」暴露薪资区间，且人社部劳科院已发布 per-role per-region 市场平均招聘薪酬（免费权威）。常见岗 + 一二线城市数据质量中高，足以支撑「offer 在市场区间的什么位置」。**但有限制**：招聘薪资 vs 到手有 10–30% 口径差；同名岗位职级 / 职责跨公司不可直接比；冷门岗 / 应届 / 私企数据稀薄——稀薄处明确标「无法评估」，绝不编造百分位。

### 9.1 检索话术
- `岗位名 城市 薪资 2026` / `岗位名 城市 Boss直聘 薪资范围`
- `岗位名 城市 看准 薪资爆料` / `岗位名 城市 职友集 薪资`
- 官方锚点（可选）：人社部劳科院《市场平均招聘薪酬》季度发布（44 数字热门岗 + 36 典型岗，按区域 / 行业）。

### 9.2 落位到报告（薪酬真实度维度）
- 用户给了具体 offer 数字 → 拉市场区间，标注「高于 / 持平 / 低于市场水位（约 X–Y 区间）」。
- 没给 offer → 只给市场区间作谈薪参考，不替用户下定。
- 跨城市 / 跨职级必须同口径（「岗位 + 城市 + 经验档」三要素收敛），禁止拿一线高级岗比本地初级岗。
- 冷门岗 / 稀疏数据 → 标「薪资市场基准无法评估（样本稀薄）」，不强行给数。

### 9.3 常见坑
- 招聘薪资常含绩效 / 年终（总包），到手低 10–30%，交叉验证时提醒看 base。
- 同 title 不同 scope（如「市场经理」管一区 vs 管全国）薪资差很大，以「职责 + 职级」双要素对齐再比。
